A Hugging Face dataset card is the README.md at a dataset repository's root, which the Hub renders on the dataset page and reads for machine-readable YAML metadata that drives discovery, filtering and license display. It is worth knowing now because a large-scale study of all 7,433 dataset documentation entries on the Hub found documentation quality tracks dataset popularity closely, and because card structure is now the de facto standard for documenting open datasets.
