Letta is a platform for persistent agents whose identity, conversations and editable memory persist across sessions. Its current open-source harness is Letta Code, using git-backed Markdown memory (MemFS) rather than the retired V1 API server, and it is worth knowing now because memory is stored as inspectable files instead of requiring a vector database by default.

## Thesis

Letta is worth evaluating for recurring work needing durable, inspectable context because its current design stores memory as versioned Markdown files without requiring a vector database, but its benefits for a specific workload and its operating costs remain unproven in the pages read.

## What it is

Letta provides a CLI, desktop app, web interface, messaging channels and a TypeScript Agent SDK for agents with durable context. Memory as files: Markdown files under system/ enter each turn's system prompt, other files are read on demand, edits become shared memory after commit and push, and an optional search mod can add semantic or hybrid retrieval with QMD. Local runtime and self-hosted App Server can retain state without a Letta account, but remote model providers still receive prompts and operators manage backups.

## Traction

- Letta Filesystem scores 74.0% on the LoCoMo benchmark by simply storing conversational histories in a file, beating out specialized memory tool libraries [https://www.letta.com/research/]
- Letta reports achieving 42.5% overall score on Terminal-Bench ranking 4th overall and 2nd among agents using Claude 4 Sonnet [https://www.letta.com/research/]
- Current release checked is v0.32.11, published September 15, 2026 [https://rywalker.com/research/letta]
- Letta's research page lists FrontierMemory (OCT 2026), Evaluating Memory in Production Agents (JUL 2026) and Memory Models (JUN 2026) among recent research items [https://www.letta.com/research/]
- Trajectory is described as an open-source package that normalizes coding-agent sessions from Claude Code, Codex, Letta Code, and other harnesses into one token-efficient format [https://www.letta.com/research/]

## Risks

- Remote model providers still receive prompts even with local state/self-hosting, and self-hosted state needs the operator's own backups.
- The $20 base price does not mean unlimited inference; plans have different billing units and usage charges.
- Old Python-server / V1 tutorials are not current deployment instructions, risking wrong setup.
- The 'agent reviews before applying' dreaming option adds a model conversation and token cost and is not a human approval step.
- Memory quality and maintenance need explicit evaluation; the pages do not establish improved accuracy on a particular workload.
