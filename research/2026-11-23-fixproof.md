FixProof 0.3.0 is an MIT-licensed agent skill and command-line tool for verifying AI code fixes rather than trusting them. ## Thesis

FixProof is a small, stdlib-only verification tool with recent real commit activity, but its own pages qualify its tamper resistance. I conclude it is worth knowing as a verification pattern, not as proven independent assurance, because evidence chaining helps only when the log is not controlled by the agent being verified.

## What it is

The skill tells an agent to reproduce a bug and edit code, while scripts/verify.py runs the commands, stores evidence, and chooses the status. It uses only Python 3.9 or newer and the standard library, with no package to install. Each run record stores the hash of the previous record, and validate recomputes that chain and the status from the records.
