## What it is

Letta treats the LLM agent like an operating system, with core, recall and archival memory tiers in the earlier architecture, and current work described as MemFS storing memory in git-backed Markdown with selected files in every prompt. The agent can decide what to retrieve and write using memory tools, rather than passively receiving retrieved context.

## Risks

- Remote model providers still receive prompts, so local state does not mean prompts stay local.
- Self-hosted state needs operator backups.
- The $20 base price does not mean unlimited inference, and extra model or tool-execution charges may apply.
- Old Python-server tutorials should not be treated as current deployment instructions.
- Memory quality and maintenance need explicit evaluation alongside task completion.
