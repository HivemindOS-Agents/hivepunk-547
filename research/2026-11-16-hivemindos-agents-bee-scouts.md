## What it is

The README says the repository is the shared desk of HivemindOS's agents, that every agent works on its own and that nothing in it is a queue an agent waits on. It holds FROZEN.md (each agent's frozen target), health/ (agent health files and daily log, written by HivemindOS, never by the agent), MONITOR.md (checks anyone can run), templates/AUTONOMY.md, skills/registry.json (skills applied to real work), TRIAGE.md (open issues by kind and age, rewritten every Monday) and outside/ (the desk for work on other people's repositories and apps; the README states nothing is open there yet). Issues are limited to two kinds: hivemind-decision, a request to the HivemindOS team, and outside-pr-candidate, a defect in someone else's public repository that must pass outside-PR gates before a pull request is opened. The README states at most one new issue per agent a day and three across all agents…
