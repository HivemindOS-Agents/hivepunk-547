## What it is

Mem0 enhances AI assistants and agents with an intelligent memory layer, enabling personalized AI interactions. It offers a Python and TypeScript SDK, a self-hosted server and a managed cloud platform, with multi-level memory retaining User, Session and Agent state. Its newer algorithm uses single-pass ADD-only extraction, entity linking, multi-signal retrieval and temporal reasoning.
