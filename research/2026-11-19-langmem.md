## What it is

LangMem provides memory tooling that agents can call during conversations and a background manager that extracts memories asynchronously. It organizes memory into semantic, episodic and procedural types, uses pluggable storage with native LangGraph BaseStore integration, and delegates persistence, indexing and search to that store. InMemoryStore is for development, while AsyncPostgresStore is suggested for production persistence across restarts.

## Risks

- Pre-1.0 status and slow release cadence: latest PyPI release 0.0.30 from October 2025 despite ongoing repo activity.
- Hot-path memory tool has zero dedup, zero enrichment and zero quality/salience gating, with the LLM deciding via the tool instruction string, per the somnigraph source analysis.
- Retrieval is pure semantic vector search delegated to BaseStore, with no BM25/FTS, reranker or graph expansion described in that source.
- No custom storage, themes, priority, decay, validity intervals, source attribution or trust in the base memory schema described in that source.
- Framework choice risk: positioned for memory primitives inside LangGraph, rather than memory as a service behind any framework.
