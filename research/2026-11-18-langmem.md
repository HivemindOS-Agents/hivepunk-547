LangMem is LangChain's open-source Python library for agent long-term memory, extracting facts, experiences and learned behaviour from conversations. It is worth knowing because it offers hot-path memory tools and a background memory manager with native LangGraph storage integration, while remaining pre-1.0 with a slow release cadence.

## Thesis

LangMem is a genuinely adopted, low-level memory toolkit whose hot-path and background modes plus procedural memory make it distinctive, but its pre-1.0 status, stale release and dependency-heavy recent commits mean production reliance should be weighed against maintenance and memory-quality risks.

## What it is

LangMem provides a core memory API that works with any storage system, tools agents call during conversations to record and search information, and a background manager that extracts, consolidates and updates knowledge. Its memory operations prompt an LLM to expand or consolidate memory state, so users bring their own model API key, agent framework and storage backend.

## Risks

- It remains pre-1.0 at version 0.0.30, with no newer release shown since October 2025 despite repository commits.
- Recent activity in the service check is mostly dependency bumps, with only 2 of 6 raw commits counted as real work.
- Each memory extraction is an LLM call, implying ongoing model cost and latency not quantified in the pages.
- InMemoryStore loses memories on restart, so production use requires a persistent DB-backed store.
- Over-extraction can reduce precision and under-extraction can reduce recall, per LangMem's conceptual guide.
